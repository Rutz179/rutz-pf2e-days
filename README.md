# Rutz's PF2e Days

[Discord](https://discord.gg/bB7Ca666Bv) · [Wiki](https://github.com/Rutz179/rutz-pf2e-days/wiki)

Plan how the party spends its days: drag activities onto each character's waking hours and advance as many days as you like.

- **Day bar** — Craft, Treat Wounds, rituals, training, Earn Income, Subsist, errands, the character's own downtime actions… Plans stay until changed, for every day or one weekday.
- **Advance** — +1 / +3 / +7 / N days: the world clock moves and the chat card shows who did what. Staying up too long leaves you fatigued; sleeping runs Rest for the Night.
- **Checks** — the GM asks, each player rolls on a chat card. Earn Income pays at once by the rules; Subsist.
- **Calendar** — Golarion's months from PF2e's world clock; pass time to any day.

## Install
Foundry → *Add-on Modules* → *Install Module* → Manifest URL:
```
https://github.com/Rutz179/rutz-pf2e-days/releases/latest/download/module.json
```
